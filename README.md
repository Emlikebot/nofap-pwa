# 自律打卡（戒色打卡 PWA）

纯静态网页应用，无需后端，数据保存在本机浏览器（localStorage），可离线使用。

## 功能
- **首页**：实时计时（天 / 时:分:秒）、里程碑进度环、每日打卡（心情 + 日记）、最长记录 / 连续打卡 / 累计打卡、每日一句、"我为什么要坚持"
- **日历**：按月查看打卡（绿色）与破戒（红色）、打卡日记列表
- **急救**：方块呼吸引导动画、"立刻做一件事"清单、激励语 / 我的理由、"我赢了"记录战胜冲动次数
- **成就**：12 枚里程碑勋章（1 天 → 1000 天）、破戒记录与诱因统计、修改开始时间、导出 / 导入 JSON 备份、清空数据

## 安装到 iPhone
PWA 需要通过 **HTTPS** 访问才能离线缓存。把整个文件夹部署到任意静态托管：
- GitHub Pages：新建仓库 → 上传本目录所有文件 → Settings → Pages 开启
- Netlify / Vercel / Cloudflare Pages：直接拖拽文件夹上传

然后在 iPhone **Safari** 打开网址 → 点底部"分享" → **添加到主屏幕**，即可全屏像 App 一样使用。

## 本地预览
```bash
python3 -m http.server 8000
```
浏览器打开 http://localhost:8000

## 文件
- `index.html` 应用全部界面与逻辑
- `manifest.webmanifest` PWA 配置
- `sw.js` 离线缓存（修改文件后把 `CACHE` 版本号 +1，用户端才会更新）
- `icons/` 图标；`make_icons.py` 可重新生成图标
